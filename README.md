# 最后的林地

一款守护古树的浏览器生存游戏。操控随机动物角色，抵御四面来袭的波次怪物，并探索三十二个野区营地。

## 游玩

打开 [最后的林地](https://drgwc.github.io/last-grove-game/)。

## 双人联机

1. 两名玩家分别打开游戏页面。
2. 一名玩家点击「🌐 双人联机 / 加入房间」或游戏内「🌐 联机」，再点「创建房间」。
3. 把生成的 8 位房间码发给另一名玩家；对方输入房间码并加入。
4. 房主点击「开始守护」。房主负责运行本局；队友可移动、攻击、购买装备并请求回树，双方共享怪物、古树、波次和金币状态。
5. 房间只支持房主加一名队友。房主关闭页面或断开联机后，本局联机会结束。

联机使用 PeerJS Cloud 交换连接信息；建立连接后，游戏状态通过浏览器间的 WebRTC 点对点数据通道传输。双方需要可访问网络，部分限制较严的校园、公司或移动网络可能阻止点对点连接。

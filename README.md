# 武侠世界

《武侠世界》是一款单人、开放地图的武侠生存动作游戏。无名游侠从一根粗木棍和普通布衣开始，在安平镇和山野间移动，自动施展已习得的武学，收集阅历、躲避强敌，并在每次突破时选择新的武学或强化。

## 游玩

线上游戏：[武侠世界](https://drgwc.github.io/last-grove-game/)

本地预览：

```sh
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 操作

- `WASD` 或方向键移动；电脑上点击地图也可以走到指定位置。
- `Shift` 闪避。
- `1`–`4` 或 `Q` / `E` 切换已学会的武学。当前招式会自动寻找附近目标。
- `B` 打开行囊；`M` 打开山河图。打开行囊时战斗会继续。
- 手机上拖动屏幕摇杆移动，使用右侧按钮闪避和切换武学。

每个角色最多携带四门武学。拳脚、剑气、刀芒、枪劲、扇骨、指力、掌风、飞针和剑雨各有不同的攻击轨迹与命中反馈。山寨头目、巫师、弓手和山蛟会用各自的攻击方式反击。

# 武侠世界

《武侠世界》是一款单人、开放地图的武侠生存动作游戏。无名游侠从赤手空拳开始，在安平镇和山野间移动，自动施展已习得的外功、内功与轻功，收集阅历、躲避强敌，并在突破时选择新的武学或强化。

## 游玩

线上游戏：[武侠世界](https://drgwc.github.io/last-grove-game/)

设计画廊：[浏览角色、怪物、场景、环境素材与招式效果](https://drgwc.github.io/last-grove-game/design-gallery.html)

本地预览：

```sh
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 操作

- `WASD` 或方向键移动；电脑上点击地图也可以走到指定位置。
- `Shift` 闪避。
- 外功、内功与轻功会各自自动寻找目标并行施展；最多习得八门武学。
- `B` 打开行囊；`M` 打开山河图；`Esc` 关闭面板。打开行囊时战斗会继续。
- 手机上拖动屏幕摇杆移动，使用右侧按钮闪避。

拳脚、剑气、刀芒、枪劲、扇骨、指力、掌风、飞针和剑雨各有不同的攻击轨迹与命中反馈。山寨头目、巫师、弓手、异兽与山蛟会用各自的攻击方式反击。

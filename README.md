# 武侠世界

《武侠世界》是单人浏览器动作游戏。角色从赤手空拳和粗布短衫开始，在安平镇自由行走；村民遭袭时可以自行回防，也可以沿青岚山道挑战山寨头目与火鳞山蛟，寻找原创武学、兵刃、衣装和灵宠。游戏没有接取任务流程，行囊与武学面板打开时世界仍会继续运行。

## 游玩

打开线上游戏：[武侠世界](https://drgwc.github.io/last-grove-game/)。

本地预览可在项目目录运行：

```sh
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 操作

- `WASD` 或方向键移动；也可以点击地面行走。
- `空格` 或 `J` 攻击；`Shift` 闪避。
- `E` 与南门、铁匠铺和灵宠互动。
- `Q` 施展当前武学，`C` 切换已习得的武学。
- `B` 打开行囊与装备，`K` 查看武学图谱。

手机可用左侧摇杆移动，右侧按键攻击、施展武学或互动。进度保存在当前设备的浏览器中。
